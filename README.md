# JDBC Employee Management System

A Java console-based CRUD application built using JDBC and the H2 in-memory database.

## Features

- Add Employee
- View Employees
- Update Employee
- Remove Employee
- JDBC PreparedStatement implementation

## Tech Stack

- Java
- JDBC
- H2 Database

## Run

Compile:

```bash
javac -cp ".;lib/h2-2.5.252.jar" src/com/jdbc/EmployeeOperation.java
```

Run:

```bash
java -cp ".;lib/h2-2.5.252.jar;src" com.jdbc.EmployeeOperation
```
